## Как проверять сведения

Начните с [регистрации HTTP-роутеров](../src/__init__.py), затем перейдите по ссылкам из соответствующего основного документа к обработчикам, зависимостям, доменным моделям и тестам. Для локального запуска тестов сначала изучите [правила backend](../AGENTS.md): импорты при collection могут требовать настроек, интеграционные сценарии используют внешние сервисы; полный запуск приложения здесь не требуется.
