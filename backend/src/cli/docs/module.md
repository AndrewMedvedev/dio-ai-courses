# Модуль `cli`

## 1. Название и краткое описание

`cli` содержит CLI-команды проекта. Существующий `backend/src/cli/README.md` не изменялся; этот файл добавлен внутри `docs/` согласно ограничению не перезаписывать существующие Markdown-файлы.

## 2. Границы ответственности

**Делает:** предоставляет команды для запуска проектных операций из CLI. **Не делает:** не предоставляет HTTP API.

## 3. Глоссарий

| Термин | Значение |
|---|---|
| CLI command | Команда, вызываемая через Python entrypoint/module. |
| Bootstrap command | Команда, которую может запускать `core/lifespan.py` через `run_cli_command`. |

## 4. Структура папок

```text
backend/src/cli/
├── __init__.py
├── __main__.py
├── commands.py
├── README.md       # существующая документация, не изменялась
└── docs/module.md  # этот файл
```

## 5. Доменная модель

Не применимо: доменных entities нет.

## 6. Ключевые сценарии (use cases)

| Сценарий | Входные данные | Шаги | Результат | Ошибки |
|---|---|---|---|---|
| Запуск CLI | args command | `__main__.py` → `commands.py` | выполнение команды | runtime errors команды |
| Bootstrap из startup | command name | `core/lifespan.py` → `run_cli_command` | подготовка приложения | startup fail при ошибке |

## 7. Публичный API модуля

HTTP/gRPC endpoints нет. Публичный интерфейс — CLI-команды из `commands.py` и entrypoint `__main__.py`.

## 8. События

Не применимо: events не найдены.

## 9. Хранение данных

Собственных таблиц нет. Команды могут работать с БД через другие модули; конкретные побочные эффекты нужно смотреть в `commands.py`.

## 10. Зависимости

`core/lifespan.py` вызывает CLI bootstrap через `src.shared.utils.cli.run_cli_command`. Остальные зависимости определяются конкретными командами.

## 11. Конфигурация

Не удалось однозначно выделить отдельные параметры из кода без детального разбора каждой команды; см. «Открытые вопросы».

## 12. Фоновые процессы

Не применимо: CLI запускается вручную или на startup.

## 13. Безопасность и права доступа

HTTP auth не применяется. Безопасность зависит от окружения запуска CLI и прав процесса.

## 14. Каталог ошибок модуля и их HTTP-статусов

### a) Единый формат ошибки

Не применимо: HTTP endpoints нет.

### b) Таблица ошибок

| Ошибка | HTTP | Когда | Где |
|---|---:|---|---|
| Runtime exception | не HTTP | Ошибка команды | `commands.py`/вызываемые сервисы |
| Startup exception | не HTTP | Bootstrap command падает | `core/lifespan.py` |

### c) Правила маппинга

HTTP-маппинга нет.

### d) Формат ошибок валидации

Не применимо.

## 15. Тестирование

Тесты `cli` не найдены.

## 16. Как с этим работать разработчику

Новые команды добавляйте в `commands.py` и документируйте в существующем `README.md` или отдельном файле в `docs/`, не смешивая CLI с HTTP API.

## 17. Наблюдения и технический долг

- CLI bootstrap запускается из `core/lifespan.py`, поэтому ошибка команды может сорвать старт приложения.
