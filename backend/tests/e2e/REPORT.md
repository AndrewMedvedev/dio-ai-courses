# Проверка HTTP API модулей `courses` и `llm_router` — 10 ноября 2026 года

## 1. Краткие итоги

Проверен **ограниченный контур без изменения данных** уже запущенного сервера: `/health`, `/openapi.json`, публичный поиск курсов, обработка некорректных UUID и пагинации, отказ анонимным пользователям на защищённых маршрутах. В текущем коде двух модулей найдено **56 HTTP-операций**; все они присутствуют в спецификации работающего сервера. Сверены методы, пути и объявленные коды успешного ответа. Проверка всех полей DTO и всех возможных ошибок для каждого маршрута **не проводилась**. Потерянных маршрутов и повторов среди найденных сочетаний метода и пути не обнаружено.

Итого **15 успешно, 0 неожиданных падений, 5 ожидаемых падений, 2 пропуска**. Проверки с тестовыми учётными записями, изменением данных, реальными моделями и внешней инфраструктурой **заблокированы**. Интерактивная проверка через инструменты MCP Playwright также заблокирована: требуемый браузер отсутствует. **О полном покрытии API заявлять нельзя.**

Поля DTO **каждой** операции по отдельности не проверялись.

Записывающие запросы требуют подтверждения одноразового окружения и соответствующих флагов; удаление требует дополнительного разрешения. Очистка созданных тестом записей предполагалась бы через публичный API, если маршрут допускает такое удаление. В этом запуске записи не создавались.

## 5. Подтверждённые дефекты; рабочий код не исправлялся

### BUG-C01 — обновление чужого сеанса изучения теории

- **Идентификатор / серьёзность / модуль:** BUG-C01; **критический** — изменение чужих данных при знании идентификатора; `courses`.
- **Маршрут:** `PUT /api/v1/progress/theory-sessions/{theory_session_id}`.
- **Условия и воспроизведение:** пользователь A обращается к сеансу пользователя B по известному ID и передаёт допустимые метрики. В тесте репозиторий подменён; запрос представлен вызовом обработчика с `active_time_seconds=30`. Запрос к работающему серверу **не выполнялся**.
- **Ожидалось:** 403 или 404; отсутствие редактирования, обновления и фиксации транзакции. **Получено:** обработчик редактирует и сохраняет чужой сеанс.
- **HTTP-код / идентификатор запроса:** в успешной ветке код предусматривает 200; фактический HTTP-код не измерялся; идентификатор запроса отсутствует.
- **Причина и файлы:** `repo.read(uid=theory_session_id)` без сравнения `theory_session.user_id` с `_identity.id`; `src/courses/api/learning/v1/theory_session.py:51-64`, чтение репозитория без привязки к пользователю.
- **Регрессия:** `tests/unit/courses/test_theory_session_ownership.py::test_other_user_cannot_update_theory_session` — строгое ожидаемое падение. После исправления правильное поведение приведёт к неожиданному прохождению (`XPASS`) и потребует убрать отметку ожидаемого падения.
- **Влияние:** риск изменения чужих метрик; дополнительная стоимость отсутствует. **Обходной путь:** не раскрывать ID третьим лицам; это не заменяет контроль доступа. **Доказательство:** тест владельца проходит, тест чужого сеанса воспроизводит запись и фиксацию транзакции.

### BUG-L01 — несовместимая сигнатура разбора текстового ответа

- **Идентификатор / серьёзность / модуль:** BUG-L01; **серьёзный** — основной текстовый вызов прерывается после успешного ответа модели; `llm_router`.
- **Маршрут:** `POST /api/v1/responses/text`.
- **Условия и воспроизведение:** модель подменена успешным ответом; вызов `_invoke` передаёт разборщику `final_tool_name`, в том числе значение по умолчанию `None`. Реального платного вызова не было.
- **Ожидалось:** результат с `raw_text="ok"` и тремя токенами. **Получено:** `TypeError`, поскольку `parse_llm_response` не принимает `final_tool_name`.
- **HTTP-код / идентификатор запроса:** на сервере не измерялись; вероятная ошибка 5xx не выдаётся за наблюдение.
- **Причина и файлы:** несовместимость вызова в `src/llm_router/application/llm_router.py:154-159` с сигнатурой в `src/llm_router/infra/parse_response.py`.
- **Регрессия:** `tests/unit/llm_router/test_router_regressions.py::test_text_response_parses_without_unrecognised_parser_keyword` — строгое ожидаемое падение; после исправления должен возвращаться корректный результат.
- **Влияние:** возможна потеря ответа после оплаченного вызова; при сбое разбора событие учёта может содержать ноль токенов. **Обходной путь:** без исправления рабочего кода не найден. **Доказательство:** ошибка воспроизведена с подменённым поставщиком модели.

### BUG-L02 — сломан явный выбор текстовой модели

- **Идентификатор / серьёзность / модуль:** BUG-L02; **серьёзный** — маршрут с параметром выбора модели не работает; `llm_router`.
- **Маршрут:** `POST /api/v1/responses/text?model=chosen-model`.
- **Условия и воспроизведение:** реестр моделей подменён записью выбранной модели; вызов `LLMTextRouter.call_llm(..., model="chosen-model")`.
- **Ожидалось:** передача указанной модели без классификатора. **Получено:** `AttributeError` из-за `.items` у списка до обращения к модели.
- **HTTP-код / идентификатор запроса:** на сервере не измерялись.
- **Причина и файлы:** `src/llm_router/application/llm_router.py:183-187,208-213`; кроме ошибки типа, ветка выбирает модель со сложностью `MEDIUM`, а не переданное имя.
- **Регрессия:** `tests/unit/llm_router/test_router_regressions.py::test_explicit_text_model_is_used_without_classification` — строгое ожидаемое падение; после исправления должна использоваться указанная модель.
- **Влияние:** явный выбор не работает; платного вызова по этому пути не происходит. **Обходной путь:** не указывать модель, но ветка по умолчанию затронута BUG-L01. **Доказательство:** тест с подменённым реестром воспроизводит ошибку.

### BUG-L03 — игнорируется явный выбор модели изображений

- **Идентификатор / серьёзность / модуль:** BUG-L03; **серьёзный** — несоблюдение контракта выбора модели; `llm_router`.

## 6. Статические риски и неподтверждённые гипотезы

Следующие наблюдения **не включены в число подтверждённых дефектов**, поскольку необходимые сценарии не воспроизведены изолированно или на работающем сервере:
