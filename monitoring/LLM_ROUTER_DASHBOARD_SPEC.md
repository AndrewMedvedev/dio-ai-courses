# Техническое задание: дашборд запросов LLM Router

## 1. Цель

Реализовать в Grafana дашборд для просмотра запросов, поступающих в LLM Router, и соответствующих ответов.

Все запросы и ответы уже записываются в базу данных. Дашборд должен использовать эти данные для их отображения.

## 2. Референс

В качестве примера организации просмотра данных использовать LangSmith Tracing:

- список поступивших запросов;
- возможность выбрать отдельный запрос;
- просмотр содержимого выбранного запроса и соответствующего ему ответа.

Требование использовать LangSmith Tracing относится к общей логике представления и просмотра данных, а не к точному копированию интерфейса.

## 3. Место реализации

Дашборд должен быть реализован в Grafana и добавлен в каталог:

```text
monitoring/grafana/dashboards/
```

## 4. Источник данных

Источником данных является база данных, в которую LLM Router записывает:

- входящий запрос;
- ответ на запрос.

Grafana должна получать данные из этой базы данных.
